## 复习方式

回答简洁明了，默认每次直接讲十个知识点；可用考题加简短答题要点组织，不让用户先盲答陌生概念。用户追问时只解释当前疑惑。需要检查掌握情况时，采用接近期末考试的原理题、比较题或分析题，避免显然的常识确认问题。

考试范围为全部课件；作业用来确定复习切入点，不代表全部考试范围。具体题型和计算题是否出现尚未确认。
