# 移动计算带学约定

- 简洁明了，避免一次讲大量内容；一问一答，一次最多一个问题。
- 提问应接近老师可能出的简答、原理分析或技术比较题，避免显然的常识题拖慢复习。
- 优先解释用户主动追问的物理含义或机制；用户说理解了之后再推进下一点。
- 需要解释 CDMA 等机制时，优先使用小规模、能手算的具体例子。
- 按“解决什么问题、采用什么方法、收益与代价”组织知识，结合已布置的完整简答题串联复习，避免连续孤立罗列技术缩写。
- 2026-11-19 用户说明后天考试，即 2026-11-21；范围是全部课件，无已确认题型。
- 继续学习前先读“复习进度.md”，以其中当前继续学习位置为准。
- 更新学习记录、知识点笔记与进度时，明确区分“已讲解”和“用户已确认理解”。
