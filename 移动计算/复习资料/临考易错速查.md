## 八条易错规则

1. **RIP先加1**：邻居报的是邻居自己的距离；自己经邻居过去再加1。当前下一跳就是该邻居时，报告变差也必须据此更新，旧距离不能当仍有效；若另有已知更优可用路，可换路。16表示不可达。
2. **码率方向**：r=信息比特数/编码后比特数。已知信息速率，编码输出速率=信息速率/r；已知编码输出速率，有效信息速率=编码速率×r。
3. **状态数取log2**：每码元M种状态，对应log2M个固定长度编码比特；4状态是2bit，不是4bit。
4. **码片不是新增信息**：m码片/编码比特时，码片率=编码比特率×m，单位chip/s。有用信息不会因此凭空增加。
5. **EAS共享档位**：课件模型按域内最大单核负载选OPP，非负载总和；迁移先扣原核任务负载，再加到目标核。逐核util/capacity×power求和比较，勿把未给时间单位的模型值称为实测焦耳。
6. **CDMA归一化**：理想正交模型，目标码与混合信号点积后除以码长m；异码内积0，自码内积m。
7. **多普勒求差**：相向低速接收频率约f′=(1+v/c)f；最大频移是|f′−f|=vf/c，不是f′本身。
8. **功耗不等于能量**：P_dyn∝V²f，E=P×t。升档先升压后升频，降档先降频后降压；静态及其他部件功耗另计。

## 两个流程

**移动IPv4，外部代理模式：** 发现代理/CoA → 注册HoA到CoA绑定 → CN发包到HoA → HA加外层目的CoA → FA解封装交给MN。内层目的HoA不变；CN知道的是MN的HoA，不是HA地址。课件基本回程MN直接回CN，实际可有反向隧道。

**FTL更新：** 新数据写空闲页 → 更新逻辑到物理映射 → 旧页失效 → 后续GC搬走有效页再整块擦除。避免每次立即擦块，不是永远不擦除。

## 波形与地址

- 差分曼彻斯特按本课件：位开始跳变0、不跳1；位中间总跳。初始电平是发送前状态，不是数据位，也不默认首位1。初始H、数据1010 → HL|HL|LH|LH。
- 普通曼彻斯特按本课件：中间上升0、下降1；并非每位必变低。题目另有约定时按题目。
- Activity暂停：失焦但可能可见；停止：不可见；都不等于销毁。
- CIDR聚合要连续且对齐：206.0.71.128/26与206.0.71.192/26恰好合为206.0.71.128/25。
- NAT出网改源IP/端口、回程改目的IP/端口；外部端口由映射分配，不是固定算式。

## 答题收尾

- 机制题：原因 → 参与角色 → 消息/数据流程 → 收益与代价。
- 比较题：沿相同维度逐项对照，名称写准；1G—4G优缺点可看[作业答题稿](作业答题稿.md)。
- 计算题：先写公式和假设，dB换线性、统一单位，最后标单位；不会算完也保留过程。
- 未独立完整检查的图示、统计公式等仍在课件范围；瑞利积分扩展题按用户选择跳过，不以此推定不考。
