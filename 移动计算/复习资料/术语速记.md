# 术语速记（第二轮回顾）

用途：第一轮优先理解问题、机制与技术比较；零散名称、标准号和角色在第二轮集中回顾。本表不是老师已划定的考点，也不意味着未列内容不考。

| 内容 | 快速关联 |
| --- | --- |
| AS | Autonomous System，自治系统；管理和路由策略的范围 |
| RIP | Routing Information Protocol；距离向量、按跳数、Bellman–Ford 思想 |
| OSPF | Open Shortest Path First；链路状态、拓扑图、Dijkstra |
| RFID | Radio Frequency Identification，射频识别；电子标签、读写器、天线 |
| WSN | Wireless Sensor Network，无线传感器网络；大量节点、无线通信、自组织、协作感知 |
| ZigBee | 近距离、小数据、低功耗；底层基于 IEEE 802.15.4 |
| ZigBee 角色 | 协调器建网管理、路由器转发、终端采集上报（可按需休眠） |
